This is my fourth-year project, which focuses on optimizing trades in the electricity market.

The file `eac` contains the core code used to formulate the Mixed-Integer Linear Programming (MILP) model for clearing bids in the electricity market. The model aims to both maximize social welfare and minimize the market clearing price.

The file `eac_tests` includes various test cases to validate the logic of the MILP model in simple scenarios, ensuring its correctness and reliability.
